\# ⚾ BaseVision AI



AI-powered Baseball Performance \& Scouting System.



\## Overview



BaseVision AI is a computer vision and machine learning project designed to analyze baseball video and automatically extract performance and scouting information.



The system aims to detect and track:



\- Baseball

\- Pitcher

\- Batter

\- Catcher

\- Umpires

\- Fielders



\## Planned Features



\- Object detection

\- Multi-object tracking

\- Baseball trajectory analysis

\- Pitch analysis

\- Swing detection

\- Pose estimation

\- Machine learning-based scouting

\- Interactive analytics dashboard

\- Automatic scouting reports



\## Technology Stack



\- Python

\- PyTorch

\- CUDA

\- YOLO

\- OpenCV

\- BoT-SORT

\- ByteTrack

\- NumPy

\- Pandas

\- Streamlit

\- Plotly

\- Machine Learning
